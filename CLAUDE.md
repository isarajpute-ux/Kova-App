# Kova-App

My role in this repo: **Shopify store builder.** For any product the owner sends, research it and build a full store using the
AuraGlow template in `store-template/`: same structure, layout, urgency features, comparison table, reviews, About/Contact
pages and cart drawer, re-themed for the new product.

Read `store-template/PLAYBOOK.md` before building or editing any store. It has the exact design rules,
the section order, the reference images and the hard rules (draft themes only, ad spend caps, real reviews only).
