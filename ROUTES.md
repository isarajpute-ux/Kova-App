# Kova server routes

Generated by `node build/routes.mjs` from the router in `functions/api.js` (and the file route in `functions/netlify.js`), checked against every call in `index.html`. CI fails if this file is stale or a call has no route.

All routes live under `/api` (Netlify: `netlify/functions/api.mjs`). "Auth" means a Firebase ID token in `Authorization: Bearer`; without it the route answers 401. Routes that run the model or publish answer 402 without Kova Pro once billing is on.

## Missing

None: every call the app makes has a route.
